# Lunch Orders

Lunch Orders is a small browser app the team uses to collect a shared lunch order.

## Run locally

Open `index.html` in a browser.

## Browser support

Tested in current versions of Chrome, Safari, and Firefox.
Requires native ES module support in the browser.

## Run the tests

Run `npm test` with Node 22. There are no dependencies to install.

## Reverting a change

Follow `docs/revert-policy.md` when reverting a change on `main`.
